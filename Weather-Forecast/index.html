About

Weather Forecasting Using LSTM uses historical weather observations to learn temporal temperature patterns and forecast future temperature.

Objectives

Clean data, create time-series sequences, train an LSTM, evaluate it and visualize future forecasts in a standalone browser application.

Methodology

Historical Dataset → Data Cleaning → Temperature Normalization → 24-Hour Sequence → LSTM → Test Evaluation → Recursive Future Forecast → Visualization.

Future Enhancements

Multi-hour direct forecasting, GRU/Transformer comparison, more stations, rainfall and other weather features, live API integration, hyperparameter tuning and cloud deployment.
